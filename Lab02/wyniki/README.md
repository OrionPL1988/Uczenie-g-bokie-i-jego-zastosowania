# Wyniki Lab02

Ten katalog w paczce początkowo nie zawiera gotowych pomiarów. Są generowane na Twoim komputerze przez `lab02_rozwiazanie.py` albo `Lab02_uzupelniony.ipynb`.

Po uruchomieniu w **trybie pełnym** (`--full`) dodaj do GitHuba:
- `podsumowanie.json` (faktyczne metryki i ewentualne ostrzeżenia),
- `wnioski.txt`,
- 13 wykresów PNG w `wykresy/`.

Nie publikuj wyników z trybu szybkiego jako wyników końcowych. Pełne dane powinny mieć w JSON `"tryb": "pełny"`.
